## 📋 Sobre o Projeto

Landing Page comercial e **Electronic Press Kit (EPK)** desenvolvidos para a **DJ Madame Mazzam**. O projeto foi concebido com estética *dark luxury*, combinando alta conversão para contratação de eventos com uma vitrine interativa de curadoria musical e material promocional para contratantes, curadores e agências.

### 🎵 Identidade Musical & Nichos Atendidos
* **Vertentes:** House, Melodic House & Techno, Afro House, Nu Disco e Jackin House.
* **Ambientes:** Beach Clubs & Sunsets, Restaurantes de Alta Gastronomia, Arenas de Beach Tennis, Eventos Corporativos e Confraternizações.

---

## ✨ Funcionalidades Principais

* **Aviso Estratégico de Temporada & Agenda:** Banner dinâmico comunicando disponibilidade regional (Temporada Nordeste) e abertura oficial da agenda de fim de ano.
* **Players Incorporados (YouTube & SoundCloud):** Reprodução direta de sets gravados ao vivo na página sem necessidade de redirecionamento externo.
* **Digital Press Kit (EPK):** Galeria promocional categorizada (*Sunset / Golden Hour* e *Night / Club & Skyline*) pronta para divulgação e curadoria.
* **Formatos de Contratação & Rider Técnico:**
  1. *Performance DJ* (para locais com cabine e sonorização completas).
  2. *Performance DJ + Rider Próprio* (Controladora Pioneer XDJ-RR, Headphone Pioneer DJ e cabeamento XLR/RCA balanceado).
  3. *Full Experience* (Performance + Setup Próprio + Sonorização dimensionada).
* **Formulário Inteligente de Cotação:** Captura dados de data, duração do set (horas), CEP/bairro e formato desejado, gerando automaticamente uma mensagem estruturada para atendimento rápido via **WhatsApp**.

## 🚀 Como Rodar Localmente

Caso deseje testar ou editar o projeto no seu computador:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. **Acesse a pasta do projeto e instale as dependências:**
   ```bash
   cd seu-repositorio
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Acesse no navegador o endereço local exibido no terminal (geralmente `http://localhost:5173`).
